# Поддержка SC1 в локальном SC-Studio

## Запуск и открытие

```sh
cd /home/justflyne/projects/sc-studio
.venv/bin/sc-studio
```

В File → Open выбирай основной ui.sc. Файл ui_tex.sc должен лежать рядом:
он подхватывается автоматически. Поддерживаются также суффиксы highres/lowres
из тегов документа. Если открыт отдельно *_tex.sc, доступен документ текстур.
В строке состояния основной документ отмечается SC1.

File → New SC1 создаёт новый SC1. Обычная команда New создаёт SC2 v6.

## Чтение и редактирование

SC1 преобразуется в общую модель ресурсов редактора: shapes, movieclips,
textfields, exports, маски, матрицы и преобразования цвета. Поэтому работают
имеющиеся панели свойств, геометрии и анимации, просмотр атласов, экспорт PNG,
замена изображений, клонирование и перенос ресурсов, undo/redo и MCP.

Поддерживаются:

- контейнеры SC v1–v4 с LZMA или Zstandard, несжатые tag streams;
- LZHAM / SCLZ через pylzham (установлен в текущем .venv);
- shapes 2/18 и bitmap commands 4/17/22; координаты twips и порядок вершин
  преобразуются в triangle strip, используемый существующим preview;
- movieclips 10/12/35/49, кадры 11, scaling grid 31, банк 41;
- текстовые поля 7/15/20/21/25/33/43/44/46;
- матрицы 8/36, цвета 9, дополнительные банки 42, маски 38/39/40;
- raw-текстуры, плитки 32×32 (включая неполные края), встроенные KTX 45 и
  ссылки на внешние текстуры 47.

Почти миллион матриц в пользовательском ui.sc хранится в компактном массиве.
При обращении к одной матрице не создаётся весь банк Python-объектов.

## Сохранение

Save сохраняет SC1 в исходном формате контейнера и с исходным типом сжатия.
Save As записывает основной файл и его texture companions под новым именем,
например copy.sc + copy_tex.sc. Ссылки на внешние KTX/SCTX сохраняются;
при Save As соответствующие файлы копируются с проверкой конфликтов.

Неизменённые теги ресурсов, матрицы, изображения, неизвестные теги и хвосты
известных ресурсов сохраняются исходными байтами. Без правок проверенная пара
ui.sc + ui_tex.sc записывается побайтово идентично. При правках MD5 контейнера
пересчитывается. Хвост START с метаданными v4 сохраняется как непрозрачные байты;
внутренние значения этой таблицы редактор не пересчитывает.

Публикация и перенос графа в новый документ могут выдавать SC2 v5/v6 через
существующую модель ресурсов. Неизвестные SC1-теги и custom properties, которым
нет соответствия в SC2-модели, сохраняются при native SC1 save, но не переносятся
в SC2. Для редактирования с сохранением всех исходных тегов используй Save/Save As.

## Проверки и границы

Проверена пользовательская пара из корня проекта: 10260 ресурсов, 2016 экспортов,
четыре атласа, 16 банков, 982970 матриц. Все ссылки проходят Document.validate().
Проверены побайтовое сохранение и повторное открытие после правок текста,
геометрии и FPS. Файлы пользователя при проверках не изменялись.
Через окно приложения проверен preview экспорта battle_end_bg. Полный набор:
242 passed, 5 skipped. Результаты и SHA-256 входных файлов — в
[sc1-verification.json](sc1-verification.json).

Автоматические тесты tests/test_sc1.py используют собственные небольшие
SC1-файлы. Проверяются контейнеры, raw/tiled-пиксели, RGB5_A1, текст UTF-8,
правки кадров и геометрии, метаданные, новые банки, клонирование, создание SC1,
импорт в SC2, GUI preview, undo/redo и MCP. Проверку настоящего файла включают так:

```sh
SC1_SAMPLE=/путь/к/ui.sc .venv/bin/python -m pytest tests/test_sc1.py -q
```

Не поддержаны устаревшие movieclip tags 3/14, подписанные SIG-контейнеры и
Zstandard-фреймы без заявленного размера. Неизвестные drawing commands
сохраняются, но не визуализируются. SCTX сохраняется/копируется без preview,
как и в прежней версии SC2. Preview остаётся приблизительным; запуск изменённых
файлов в игровом движке здесь не проверялся.

## Источники формата

Реализация находится в sc_studio/sc1.py и подключена к Document.load/save.
Использованы следующие исходники как справочники бинарного формата:

- [SupercellFlash](https://github.com/sc-workshop/SupercellFlash), revision `41e894d5a20cc17e47fe32db3106c4c1bec60a3e`.
- [sc-py](https://github.com/xcoder-tool/sc-py), revision `0f37c1dca8ad2063e837f12626872481aa529f69`.
- [SCEditor](https://github.com/ToxicLand/SCEditor), revision `c9da9544514a4b6f7f066a5e2f651315c19009f3`.
- [sc-compression](https://github.com/xcoder-tool/sc-compression), revision `e5f45710ab01a4051f23ed688aae132f1641f60f`.

Уведомления MIT для sc-py и sc-compression сохранены в
sc_studio/third_party/SC1_LICENSES.txt; уведомление SupercellFlash уже включено
в THIRD_PARTY_LICENSE.txt. SCEditor использовался как дополнительный справочник;
его C#-код не включён в Python-проект.
