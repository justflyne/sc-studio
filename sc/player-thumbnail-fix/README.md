# Исправление PlayerThumbnail

В текущем `sc/ui.sc` восстановлены штатные ресурсы из UI клиента v59:

| Экспорт | ID клипа | Назначение |
| --- | ---: | --- |
| `shop_popupitem_27` | 219 | Popup с иконкой, названием и информацией |
| `offer_item_profilepic_big` | 240 | Большая карточка предложения |
| `offer_item_profilepic_small` | 230 | Маленькая карточка предложения |
| `brawlpass_reward_premium_playericon` | 281 | Основной ресурс PlayerThumbnail и награда пропуска |
| `mastery_reward_profile_icon` | 279 | Иконка в наградах мастерства |
| `mastery_reward_small_profile_icon` | 276 | Маленькая награда мастерства |
| `item_player_thumbnail` | 16809 | Общий элемент иконки; существующий ID сохранён |

Каждый ресурс содержит штатный слот `icon_ph` типа MovieClip. В
`item_player_thumbnail` исправлены структура и преобразования по образцу v59.
Дополнительно имя `mastery_small_profile_icon` ссылается на тот же маленький
ресурс мастерства для совместимости с этим вариантом названия.

## Установка

Замени в распакованном APK **оба** файла из папки `assets/sc/` этого набора:

- `assets/sc/ui.sc`;
- `assets/sc/ui_tex.sc`.

Эта же обновлённая пара лежит в основной папке `sc/` проекта и сохранена в
SC Studio. Архив `../player-thumbnail-fix.zip` содержит только эти два файла.
В этом архиве CSV отсутствуют. Дополнительные изменения для SavBrawl 39.99
описаны ниже.

Для сверки с уже подготовленной строкой `PlayerThumbnail`:

| Поле | Имя экспорта |
| --- | --- |
| `ShopItemAsset` | `brawlpass_reward_premium_playericon` |
| `PopupItemAsset` | `shop_popupitem_27` |
| `OfferAssetSolo`, `OfferAssetHalf`, `OfferAssetHeroLayout` | `offer_item_profilepic_big` |
| `OfferAssetQuarter` | `offer_item_profilepic_small` |

## Отображение и проверка

В SC хранится шаблон со штатной заглушкой в `icon_ph`. Конкретную иконку в игре
подставляет клиент по записи `player_thumbnails.csv`, её `IconSWF` и
`IconExportName`. В редакторе без данных предложения видна заглушка.

В `previews/` находятся рендеры шаблонов с подставленными настоящими
`player_icon_creator_3_26` и `player_icon_creator_4_26`. Подстановка всех 80
экспортов `player_icon_*` из текущего UI проверяется во всех семи контекстах
PlayerThumbnail файловым рендерером. Приложение на устройстве не запускалось.

`verification.json` содержит результаты проверки сохранённых файлов. Старые
ресурсы, экспорты, текстуры и матрицы сохраняются; из прежних ресурсов изменён
только `item_player_thumbnail`. Все пять ранее добавленных creator/dev-ресурсов
сохранены. Резервная копия до исправления находится в соответствующей папке
`../backups/player-thumbnail-*`, точный путь указан в отчёте.

## Регистрация creator-иконок в SavBrawl 39.99

В предоставленном клиенте `../SavBrawl_39.99/` таблица `player_thumbnails.csv`
содержала 78 записей с индексами 0–77. Предложение с `ItemDataId: 28000078`
ссылалось на отсутствующую запись. В эту таблицу добавлены две строки:

| ID | Имя и экспорт |
| ---: | --- |
| `28000078` | `player_icon_creator_3_26` |
| `28000079` | `player_icon_creator_4_26` |

Обе строки используют `IconSWF: sc/ui.sc` и `IsReward: true`. Прежние строки и
их порядок сохранены. Исправленная таблица находится в
`../SavBrawl_39.99/assets/csv_logic/player_thumbnails.csv`; отдельный архив
`../savbrawl39-thumbnail-csv-fix.zip` содержит только эту таблицу.

В предложении первой creator-иконки используется `ItemDataId: 28000078`.
Серверу при выдаче награды нужны те же ID.
Подробности и путь к резервной копии записаны в `savbrawl39-registration.json`.

## Исправление сервера prod39 и фона popup, 15 октября 2026

На VPS `root@savbrawl.fun`, проект `/root/prod39`, исправлены исходники и
скомпилированные классы. **Сервер не перезапускался. Самостоятельно
перезапускать сервер запрещено пользователем; перезапуск выполняет он сам.**
До ручного перезапуска работающая JVM продолжает использовать старый код.

В `SavBrawl/Logic/Home/Items/Offer.java` для `PlayerThumbnail` последний VInt
награды теперь содержит индекс иконки, полученный из `ItemDataId`:
`28000078 → 78`, `28000079 → 79`. Ранее в этот слот записывался `SkinDataId`,
по умолчанию равный нулю. Название `ExtraData` относится к этому внутреннему
слоту протокола; новое поле в JSON не требуется. Формат других типов наград
сохранён.

В `ClientHome.PurchaseOffer` добавлена выдача иконки через штатный drop типа 5.
Проверка существования иконки, количества и повторного владения выполняется до
списания валюты. Тест `tests/PlayerThumbnailShopRegression.java` прошёл 302
проверки на VPS, включая исходное предложение из `JSON/offers.json`.

У `shop_popupitem_27` фон заменён на ресурс 10379 из собственного UI 39.99.
Размеры и положение панели сохранены. Новые атласы 5 и 6 преобразованы из
KTX/ASTC в RGBA SC1; декодированные пиксели совпадают побайтово. Атласы 0–4,
экспорты и банки матриц сохранены. `libg.so` не изменялась.

Обновлённая пара UI находится в SC Studio, в распакованном клиенте
`../SavBrawl_39.99/assets/sc/` и на VPS в
`/root/prod39/SavBrawl/Logic/Assets/sc/`. Проверено, что asset-сервер выдаёт оба
новых файла по HTTP с правильными хешами. Клиент сможет получить их через
обновление контента. Если обновление контента не используется, архив
`../savbrawl39-player-thumbnail-fix.zip` содержит четыре файла для замены в APK:
пару UI, исправленный `shop_items.csv` и таблицу иконок.

Резервная копия сервера:
`/root/prod39/backups/player-thumbnail-20261015-000756/`.
Копии изменённых Java-файлов и теста находятся в `server-prod39/`.
Актуальный отчёт по UI — `savbrawl39-ui-fix.json`; исходный
`verification.json` сохраняет историю импорта и проверок до адаптации фона.
На устройстве игру не проверяли.
