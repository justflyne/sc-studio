# Загрузчик для кастомной Frida с вшитым скриптом

**Вставляй в свою сборку `embedded-loader.js`.** Это обычный самозапускающийся
JavaScript: криптография уже внутри, импортов и отдельных файлов в APK нет.
Если исходники принимают C/C++ массив, используй `embedded-script.h`.

После изменения `loader.js` пересобери файлы:

```sh
python3 frida-loader/build_embedded.py
```

Это сборка JS и header. Саму библиотеку Frida собирай существующей командой
своего native-проекта, подключив туда полученный файл.

При загрузке скрипт создаёт временную пару X25519 и cnonce, отправляет
POST `http://script.backtobs.xyz:8787/v1/script` с `have=null`, расшифровывает
ответ, проверяет SHA-256 и Ed25519, исполняет `source` и вызывает init агента.
Повторный init загрузчика ожидает тот же результат. В `loader.js` настройка
`execute: false` позволяет только скачать и проверить агент.

Подробное подключение и результаты проверок: [EMBEDDED.md](EMBEDDED.md).
Payload предназначен для текущего Android-агента с native Frida APIs.
Для изменения самой native-сборки нужен путь к исходникам твоей custom Frida.

`loader.bundle.js`, `build.py` и `GADGET.md` относятся к ранее
подготовленному варианту с ESM bundle и внешними файлами Gadget.
